# Is a five-minute prediction market efficient?

A research write-up: building a machine-learning model for Polymarket's 5-minute Bitcoin Up/Down markets, testing it against the market's own prices, and measuring what survives once execution costs and statistics are applied.

Static site (HTML, CSS, JS). Charts use Plotly; the interactive panel replays 156 simulated bets in the browser.

All figures come from simulation, not live trading, and are not investment advice.
